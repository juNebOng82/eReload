Billplz Configuration

Lets companies reload their own credit via FPX / DuitNow Transfer, without waiting for an admin reload. Get your Secret Key, X Signature Key, and Collection ID from your Billplz Dashboard → Settings → Keys & Integration.
Online reloads (paid via Billplz) get their own document number series, e.g. OL2608001 — separate from manual Reload (RC) and Adjustment (AJ) numbers.

Payment Methods

Loads the actual payment methods available on your Billplz account. Check only the ones you want customers to see — e.g. FPX and DuitNow Transfer — then save. Everything unchecked gets disabled on Billplz's side.

Service Types

A telco can support multiple service types — Reload, Bill Payment, or anything else you add. "Reload" always exists and can't be deleted. Any extra info a specific telco's version of a service needs (e.g. Digi's Reload needing a unique code that other telcos don't) is defined directly in that telco's template — see Telco Configuration.

Add new service type

Telco Configuration

For each telco, enable the service types it supports and set the USSD template for each. Templates use {PIN}, {AMOUNT}, {PHONE}, and any extra fields defined for that service type (e.g. {ACCOUNT_NUMBER}). {PIN} is filled in on the device — never sent to or stored on this server.
